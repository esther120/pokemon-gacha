# pokemon-gacha

A simple Pokemon gacha game built w/ HTML, CSS, and vanilla JavaScript.

Draw a random Pokemon from the first generation, collect Pokémon in your Pokedex, and switch between Korean, English, and Japanese names.

[Features]

🎲 Draw a random Pokémon from Gen 1 (#001–151)

⚡ Fetch Pokemon data from the PokeAPI

🔴 Poke Ball shaking animation with a minimum 1.5-second delay

📖 Collect unique Pokemon in your Pokedex

🔁 Detect duplicate Pokemon

💾 Save your collection using localStorage

🌐 Switch Pokemon names between Korean, English, and Japanese

🗑️ Reset your Pokedex and start over

❌ Handle API and network errors

[Language Support]

Pokemon names can be displayed in:
🇰🇷 Korean
🇺🇸 English
🇯🇵 Japanese

The selected language updates both the currently displayed Pokemon and the Pokemon stored in the Pokedex.
